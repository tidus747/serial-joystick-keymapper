## [Unreleased]

### Added

## [0.1.0]

### Added

- Arduino Nano firmware for four buttons and four analog axes.
- USB serial transport and frame parser.
- PySide6 desktop application.
- Live joystick monitoring.
- Per-axis calibration.
- JSON profile save and load.
- Keyboard and mouse mapping through Win32 SendInput.
- Panic stop and mapping enable controls.
